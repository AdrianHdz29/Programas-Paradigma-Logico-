# Programas-Paradigma-Logico-
Presento los archivos .pl del ejercicio, se requiere de SWI Prolog

hola_mundo es para tiene la funcion de saludar con un Hola mundo

task_resolve emplea funciones para resolver algunos problemas, haciendo una suma de una lista de numero y calcula el factorial de un numero que se le asigne.

flujo, nos permite desempeñar acciones como verificar si un numero es positivo o negrativo, igual hace un conteo ascendente o descendente.

logico demuestra las bases del lenguaje y el paradigma empleando lo fundamental, Hechos, Reglas y Consultas.
Realiza una comparacion de elementos para i terpretar la relacion.

cadena_control, realiza diferentes funciones que involucran cadenas, haciendolas en minusculas, mayusculas, contando caracteresm separando cadenas, separando caracteres, extrayendo secciones de cadenas.
